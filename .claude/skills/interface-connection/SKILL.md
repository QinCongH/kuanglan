这个 skill 用于完成前端模块的接口联调工作，包括接口调用、数据处理、空状态处理和代码整合。

## 使用方式

调用时提供以下参数：

### 参数说明

| 参数名 | 语义化含义 | 用途说明 |
|--------|-----------|---------|
| `moduleName` | 待完善模块名称 | 指定需要优化的业务模块（如：用户列表页、订单详情组件、支付接口模块等） |
| `interfaceData` | 接口目标数据 | 接口需返回的标准数据结构/字段清单，用于数据解析与渲染映射 |
| `interfaceIdentifier` | 接口唯一标识 | 接口地址/接口引用路径/接口方法名，用于精准定位联调接口 |

### 核心功能

1. **接口联调**：根据 `interfaceIdentifier` 定位目标接口，完成接口调用、参数传递、异常捕获（超时、报错、跨域等）
2. **数据处理**：接收 `interfaceData` 作为接口返回数据标准，完成字段校验、格式转换、数据过滤与渲染适配
3. **空状态兜底**：针对模块 `moduleName`，覆盖无数据、加载中、接口报错、数据为空数组等全场景，设计并实现友好的空状态展示（如占位图、提示文案、重试按钮）
4. **代码整合**：将联调后的接口逻辑嵌入当前模块引用代码，确保接口调用、数据解析与页面渲染无冲突、可直接复用

## 核心原则

### 不修改当前代码逻辑

在进行接口联调时，**必须遵循以下原则**：

1. **保持现有代码逻辑不变**：
   - 现有的业务逻辑、数据流转、事件处理等代码不可修改
   - 只进行数据源的替换（将模拟数据替换为接口数据）
   - 不重构、不优化、不清理现有代码结构

2. **只做增量添加**：
   - 新增 API 接口调用函数
   - 新增数据映射逻辑
   - 新增空状态处理（如需要）
   - 不修改已有的变量、函数、组件等

3. **数据映射规范**：
   - 接口返回字段 → 现有变量/属性（直接替换值，不改变变量名）
   - 字段类型转换 → 在映射逻辑中处理，不修改原数据存储结构
   - 饼图/列表等渲染数据 → 保持原有数据结构，仅更新 values

4. **禁止操作**：
   - 禁止删除或注释掉现有代码
   - 禁止重命名现有变量或函数
   - 禁止修改现有组件的 props、emit、slot
   - 禁止改变现有模板结构或样式
   - 禁止修改已有函数的内部逻辑

## 执行步骤

1. 读取目标模块文件，了解当前实现
2. 定位并导入指定接口
3. 替换模拟/测试数据为真实接口调用
4. 实现数据转换逻辑
5. 添加空状态处理（无数据、加载中、错误状态）
6. 确保 TypeScript 类型正确
7. 验证代码可正常运行
