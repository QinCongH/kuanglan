# 企业安全产品交互模式库

## 模式一：告警/事件列表

### 原始设计（常见反模式）
- 全量表格，所有字段平铺
- 固定排序，无优先级感知
- 点击跳转新页面查看详情

### 重构后（推荐模式）
**右侧抽屉详情模式**
- 主列表保留，右侧滑出详情面板（无需跳页）
- 关键字段：严重级别（色彩标签） + 事件摘要 + 时间 + 受影响资产
- 批量操作栏：多选后顶部出现（不占常驻空间）
- 优先级排序：严重 → 高危 → 未处理 → 已处理（视觉沉降）

**用户路径验证：**
用户想查看告警详情 → 点击告警行 → 右侧面板展开（列表仍可见）→ 查看详情 → 关闭面板（保持列表位置）✓

## 模式二：配置/策略管理

### 原始设计（常见反模式）
- 表单堆叠，一次展示全部字段
- 保存按钮在页面底部，需要滚动
- 没有状态反馈，不知道哪些配置已生效

### 重构后（推荐模式）
**分组折叠 + 内联编辑模式**
- 配置按功能域分组，用折叠面板隔离
- 每组有独立的"编辑/保存"操作（非全页面一次性提交）
- 已配置项显示当前值 + 最后修改时间 + 修改人
- 危险操作（删除策略、关闭防护）需要二次确认对话框

**用户路径验证：**
用户想修改某条告警规则阈值 → 找到"告警阈值"分组 → 点击"编辑" → 直接在行内修改数字 → 点击"保存" → 显示成功提示 ✓

## 模式三：资产/设备清单

### 原始设计（常见反模式）
- 平铺长列表，字段过多
- 搜索框功能单一
- 状态字段用文字，不够直观

### 重构后（推荐模式）
**多维筛选 + 聚合卡片模式**
- 顶部：快速统计栏（在线/离线/异常数量，可点击过滤）
- 筛选区：标签化筛选条件，已选条件以标签形式展示可删除
- 列表模式 / 卡片模式切换（用户可选）
- 资产卡片：设备名 + 状态指示灯 + 风险评分 + 最后活跃时间

---

## 模式四：操作日志/审计日志

### 原始设计（常见反模式）
- 全量表格，按时间倒序
- 无法快速定位异常操作
- 导出按钮功能弱

### 重构后（推荐模式）
**时间轴 + 热力图模式**
- 顶部：操作热力日历（可视化高峰时段）
- 左侧：时间轴视图，同用户/同IP的操作自动聚合
- 异常操作（非工作时间、首次登录IP、敏感操作）自动标记
- 右侧：操作详情面板（同告警列表模式）

---

## 模式五：数据看板/监控大屏

### 原始设计（常见反模式）
- 统计数字堆砌，无趋势感
- 图表过多，颜色混乱
- 刷新靠手动点击

### 重构后（推荐模式）
**信息层级分明的指挥台模式**
- 第一屏优先：3-5 个核心健康指标（大数字 + 趋势箭头 + 同比变化）
- 状态地图/拓扑图：可视化当前网络/系统状态
- 告警时间轴：最近 24h 告警分布（面积图）
- 实时日志流：暗色背景 + 等宽字体 + 颜色分级（模拟终端感）
- 自动刷新频率可配置（30s/1min/5min）

---

## 模式六：搜索与过滤

### 通用原则
- 搜索框支持 `key:value` 语法（如 `ip:192.168 severity:high`）
- 搜索结果高亮匹配关键词
- 保存常用搜索条件为"收藏搜索"
- 空结果页要有建议操作，不能只显示"暂无数据"

---

## 反模式汇总（必须避免）

| 反模式 | 说明 | 替代方案 |
|--------|------|----------|
| 全屏弹窗 | 操作完失去上下文 | 右侧抽屉面板 |
| 全局刷新 | 一个操作刷新整个页面 | 局部更新/乐观更新 |
| 确认对话框滥用 | 非危险操作也弹确认 | 只在删除/关闭防护等危险操作使用 |
| 表单一次性提交 | 大表单用户填写一半不敢离开 | 分步骤/分组保存 |
| 状态只用文字 | "启用"/"禁用"不够直观 | 状态指示灯 + 颜色 + 文字 |
| 操作按钮常驻 | 所有行都显示操作按钮，视觉噪音 | 悬停时出现，或选中后批量操作区 |
| 纯色占位 | 空状态只有"暂无数据" | 空状态插画 + 引导操作 |
